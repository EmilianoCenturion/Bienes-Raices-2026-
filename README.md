# 🏡 Bienes Raíces 2026

Aplicación web inmobiliaria desarrollada como práctica profesional, que permite gestionar propiedades mediante un sistema CRUD completo con panel de administración.

---

## 🚀 Funcionalidades

* 📄 Visualización de propiedades
* ➕ Creación de nuevas propiedades
* ✏️ Edición de propiedades (UPDATE)
* ❌ Eliminación de propiedades
* 🛠️ Panel de administración
* 🖼️ Gestión de imágenes
* 📱 Diseño responsive

---

## 🧑‍💻 Tecnologías utilizadas

* **PHP** – Backend y lógica del servidor
* **MySQL** – Base de datos
* **JavaScript** – Interactividad
* **SCSS (Sass)** – Estilos avanzados
* **Gulp** – Automatización de tareas
* **Node.js** – Entorno de desarrollo

---

## 📦 Instalación y uso

### 1. Clonar el repositorio

```bash
git clone https://github.com/EmilianoCenturion/Bienes-Raices-2026-.git
```

---

### 2. Instalar dependencias

```bash
npm install
```

---

### 3. Ejecutar entorno de desarrollo

```bash
npm run dev
```

---

### 4. Configurar base de datos

Asegurate de crear una base de datos y configurar la conexión en:

```
/includes/config/database.php
```

---

## 📁 Estructura del proyecto

```
├── admin/           # Panel de administración
├── build/           # Archivos compilados (CSS, JS)
├── includes/        # Configuración y funciones
├── src/             # SCSS, JS e imágenes fuente
├── imagenes/        # Imágenes del proyecto
├── anuncio.php      # Vista de propiedad individual
├── anuncios.php     # Listado de propiedades
├── index.php        # Página principal
├── nosotros.php     # Página "Nosotros"
├── contacto.php     # Formulario de contacto
├── gulpfile.js      # Automatización de tareas
```
